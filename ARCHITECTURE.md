# Folio Publisher — Architecture contract

Folio is a desktop-publishing application (a Microsoft Publisher–style editor) that runs as an
Electron desktop app on Windows 11 and macOS, and as a web app. **The structured document model is
the single source of truth.** The canvas is a rendering of it; export and print re-render from it.

This file is the contract between modules. If you change a contract, update this file.

## Layout

```
app/                    static web root (Electron loads app/index.html; GitHub Pages serves app/)
  index.html            shell markup (mount points only; UI is built in JS)
  build/app.js|app.css  esbuild output (generated by `npm run build`; not committed)
  fonts/ icons/ dict/   bundled fonts (OFL), icons, en spelling dictionary (copied at build)
  sw.js manifest.webmanifest
desktop/
  main.js               Electron main process (window, lifecycle, core file IPC)
  preload.js            exposes window.folioDesktop {platform, invoke, send, on} (channel whitelist)
  ipc-*.js              extra main-process IPC modules, auto-loaded by main.js: module.exports = (ctx) => {}
                        ctx = { ipcMain, app, dialog, shell, BrowserWindow, getWindow }
src/
  main.js               entry: imports core, engines, features; boots the app
  core/                 model, theme, units, store/app, history, registry, render, canvas, ui, persistence, platform
  engines/              independent logic with unit tests: text, table, mailmerge, spell, export, templates
  features/             ribbon tabs / panels / dialogs that wire engines into the UI via the registry
  styles/               base tokens + component CSS (imported from JS; bundled to app.css)
tests/unit/*.test.js    node --test (pure logic)
tests/e2e/*.mjs         Playwright scripts against the built app (web and Electron under xvfb)
scripts/build.mjs       esbuild bundle + asset copy
```

Build: `npm run build` (or `node scripts/build.mjs --watch`). Run desktop: `npm start`. Unit tests: `npm test`.
No framework: plain ES modules, DOM, SVG. Code style: 2-space indent, single quotes, semicolons, small modules.

## Document model (src/core/model.js — implemented; read it)

All lengths are CSS px at 96 dpi; font sizes are pt; angles degrees; opacity 0..1.
Colours are `#rrggbb`, `transparent`, or theme references `@paper @ink @accent @accent2 @muted @light`.
Fonts are family names or `@heading` / `@body`. Resolve with `resolveColor(doc, v)` / `resolveFont(doc, v)` (core/theme.js).

```
Doc {
  format: 'folio-publication', version: 2, id, title,
  setup: { width, height, units: 'in'|'cm'|'mm'|'pt'|'pc'|'px', margins:{top,right,bottom,left},
           columns:{count, gutter}, facing: bool, bleed: px, grid:{size} },
  theme: { schemeId, colors:{paper,ink,accent,accent2,muted,light}, fontSchemeId, fonts:{heading, body} },
  masters: Master[]   // >= 1. Master { id, name, background: Background|null, elements: Element[] }
  pages:   Page[]     // >= 1. Page { id, masterId: string|null, background: Background|null, guides:{v:number[], h:number[]}, elements }
  stories: { [id]: { id, html } }        // rich text, shared by a chain of linked text frames
  assets:  { [id]: { id, name, mime, data (data: URL), width, height } }   // images stored once, never modified
  data: MergeData | null                 // mail-merge recipients (see below)
  meta: { author, subject, keywords, comments, category }
}
Background = { type:'solid', color } | { type:'linear'|'radial', color, color2, angle } | { type:'image', assetId, fit:'cover'|'contain'|'tile' }
   page.background null => master background; master null => '@paper'.
Element (common) = { id, type, name, x, y, w, h, rot, opacity, locked, hidden, wrap:'none'|'square' }
  text:  { storyId, next: frameId|null, padding:{top,right,bottom,left}, valign:'top'|'middle'|'bottom', columns, colGap,
           autofit:'none'|'shrink'|'grow', fill: Fill, stroke: Stroke, radius, shadow: Shadow,
           style: { font, size(pt), color, bold, italic, underline, caps, letterSpacing(px), lineHeight, align, spaceBefore(px), spaceAfter(px) } }
  image: { assetId|null (null = picture placeholder), content: {x,y,w,h}|null (image box relative to the frame, px; null => computed from fit),
           fit:'fill'|'fit'|'stretch'|'custom', fill, stroke, radius, shadow, flipH, flipV }
  shape: { shape: SHAPE_KINDS (rect, roundRect, ellipse, triangle, …, polygon, star, arrowRight, …), sides, points, inner, radius,
           fill, stroke, shadow, flipH, flipV }
  line:  { stroke, arrowStart|arrowEnd: 'none'|'arrow'|'triangle'|'circle'|'diamond', ornament:'none'|'diamond', shadow }
         a line runs horizontally through the vertical centre of its box; use rot for angle, w for length.
  table: { cols: number[] (px widths), rows: number[] (px min heights), cells: Cell[row][col], border: Stroke, fill, style (TextStyle), headerRow, banded }
         Cell = { html, fill: color|null, align: null|'left'|'center'|'right'|'justify', valign:'top'|'middle'|'bottom', padding: px,
                  rowSpan: 1, colSpan: 1, covered: bool (true when hidden by a merge), borders: null | {top,right,bottom,left: Stroke|null} }
  group: { children: Element[] }  children keep page coordinates; group x/y/w/h = union bounds (updateGroupBounds)
Fill   = { type:'none' } | { type:'solid', color } | { type:'linear', color, color2, angle } | { type:'radial', color, color2 }
Stroke = { color, width(px; 0 = none), dash:'solid'|'dash'|'dot'|'dashDot'|'longDash' }
Shadow = { enabled, x, y, blur, color, opacity }
MergeData = { name, columns: string[], rows: string[][], excluded: number[] (row indices),
              filters: [{column, op:'contains'|'equals'|'notEquals'|'startsWith'|'empty'|'notEmpty', value}],
              sort: [{column, dir:'asc'|'desc'}], current: number (index into the filtered/sorted view) }
```

### Rich text HTML (stories and table cells)

Block elements: `<p>`, `<ul>/<ol>` with `<li>`. Paragraph styles live on the block's `style`
(text-align, line-height, margin-top, margin-bottom, margin-left, text-indent). Inline:
`<span style>` (font-family, font-size in pt, font-weight, font-style, text-decoration, color,
background-color, letter-spacing, text-transform), `<b> <i> <u> <s> <sub> <sup> <a href>`, `<br>`.
Fields (non-editable atoms): `<span class="field" data-field="NAME" contenteditable="false">«NAME»</span>`
where NAME is a merge column, or one of `#page`, `#pages`, `#date`. The renderer substitutes fields
(merge record values, page numbers) before layout; the stored HTML keeps the field spans.
All HTML entering the model must pass `sanitizeHtml()` (engines/text/sanitize.js).

## Registry and app API (src/core/registry.js, src/core/app.js)

Features never reach into each other; they register with the registry and use `app`.

```js
import { app } from '../core/app.js';
import { registry } from '../core/registry.js';

registry.command({ id, label, icon, shortcut, run(ctx, arg), enabled(ctx), checked(ctx) });
registry.tab({ id, label, order, contextual: (ctx) => bool, accent });   // contextual tabs appear when selection matches
registry.group({ tab, id, label, order, items: [Item] });
   Item = { command, size:'large'|'small'|'icon', label?, icon? }
        | { type:'custom', render(el, ctx) -> { update(ctx) } }          // selects, galleries, colour buttons…
registry.inspector({ id, title, order, when(ctx), render(container, ctx) -> { update(ctx) } });  // right panel sections
registry.elementType(type, { label, render(node, el, rctx), onDoubleClick(el, ctx), hitTest? });
registry.backstage({ id, label, icon, order, render(container, ctx) });       // File view pages
registry.preflight({ id, label, check(doc) -> [{ level:'error'|'warning'|'info', message, pageIndex, elementId }] });
registry.contextMenu({ id, order, items(ctx) -> MenuItem[] });
registry.shortcut('Mod+Shift+L', commandId);   // Mod = Ctrl on Windows, Cmd on macOS

ctx = { app, doc, session, page, pageIndex, selection (Element[]), editing (text frame id | null) }

app.doc / app.session / app.sessions                 // multiple open documents (document tabs)
app.transact(label, (doc) => { …mutate… })          // ONE undo step; re-render; dirty; autosave
app.beginGesture(label) … app.preview() … app.endGesture(commit)   // drags: many previews, one undo step
app.select(ids) / app.selection / app.page / app.goToPage(i)
app.on(event, fn): 'doc-change' | 'selection' | 'page' | 'view' | 'session' | 'render' | 'edit-start' | 'edit-end'
app.ui.toast(msg, action?) / confirm(title, html, ok) / dialog({title, body, buttons, width}) / prompt(...)
app.ui.colorPicker(anchor, value, onPick) / app.ui.contextMenu(x, y, items)
app.platform — see Platform below
```

Rendering: `renderPage(container, doc, page, { mode:'edit'|'export'|'thumb', pageIndex, record })`
(core/render). Element renderers are registered per type. Text frames get their content from
`layoutStories(doc, opts)` (engines/text/flow.js) which flows each story through its chain of frames
(frames may be on different pages) and returns html fragments per frame plus overflow flags.
Export and print call the same renderPage with mode 'export' (no handles, guides or placeholders).

## Platform (src/core/platform.js)

```js
platform.isDesktop, platform.os ('win32'|'darwin'|'linux'|'web')
platform.openPublication() -> {name, path?, text} | null
platform.savePublication({ path?, text, suggestedName, saveAs }) -> {name, path?} | null
platform.saveBinary({ data: Uint8Array|Blob, suggestedName, filters:[{name, extensions}] }) -> {name, path?} | null
platform.saveFilesToFolder([{ name, data }]) -> {folder, count} | null      // desktop; web downloads each
platform.printToPDF({ widthIn, heightIn, suggestedName }) -> {name, path} | null   // prints #print-root; web falls back to print dialog
platform.print({ copies, duplex:'simplex'|'longEdge'|'shortEdge', landscape, silent:false }) -> bool
platform.recovery: { list(), save(id, text), read(id), remove(id) }      // desktop: userData files; web: IndexedDB
platform.store: { get(key), set(key, value) }                              // small settings, custom templates
```

Desktop IPC channels are namespaced (`file:`, `export:`, `print:`, `recovery:`, `store:`, `app:`, `menu:`).
The preload exposes only whitelisted prefixes.

## Engines (pure modules with unit tests)

- `engines/text/` — `sanitize.js` (sanitizeHtml), `flow.js` (layoutStories / linked-frame flow, overflow, autofit), `fields.js` (substitute fields)
- `engines/table/` — table model operations (insert/delete rows/cols, merge/split, resize) and `renderTable`
- `engines/mailmerge/` — `csv.js` (parseCSV/toCSV), `xlsx.js` (parseXLSX via zip+XML), `merge.js` (view: filter/sort/exclude; record values)
- `engines/spell/` — `spell.js` (nspell + app/dict), `find.js` (find/replace across stories and table cells, formatting-preserving)
- `engines/export/` — `imposition.js` (sheets: normal, n-up, booklet, crop marks, bleed), `raster.js` (page -> PNG/JPEG at dpi), `pdf.js`/`print.js` (prepare #print-root)
- `engines/templates/` — template catalog (categories), building blocks, calendar generator

## History

`app.transact` records a labelled step holding the document JSON before and after (assets excluded,
since assets are immutable and append-only). Undo/redo restore snapshots; a drag, resize, rotate or
typing burst is one step. Stack depth 200 per document.

## Persistence

Native format: `.folio` (UTF-8 JSON of the Doc, `format: 'folio-publication'`). Unused assets/stories are
pruned on save. Autosave writes a recovery copy per open document every few seconds after changes;
on start, unsaved recovery copies are offered for restore. Version-1 files from the earlier app are migrated.

## Core API details

Additions and precise semantics of the core API (src/core). Everything below is implemented.

### Ribbon tabs

Built-in tab ids (registered by `features/core-tabs.js`), in order: `home` (10), `insert` (20), `pageDesign` (30),
`mailings` (40), `review` (50), `view` (60). Contextual tabs (shown only while `contextual(ctx)` is true, accent coloured):
`textFormat` ("Text Box Format": selection is one or more text frames, or a frame is being edited), `pictureFormat`
(pictures), `shapeFormat` (shapes and lines), `tableDesign` and `tableLayout` (one table selected). The File tab is the
backstage. Tab ids are matched tolerantly (`tabKey()` in registry.js lowercases, strips punctuation and resolves aliases such
as `design` / `page-design` → `pageDesign`, `picture` → `pictureFormat`, `table` → `tableDesign`), so `registry.group({ tab: 'page-design' })` works.
Groups may be registered before or after their tab; the ribbon re-renders on registry changes.

Ribbon items: `{ command, size: 'large'|'small'|'icon', label?, icon?, arg? }` (consecutive small items stack three per
column), `{ type: 'custom', render(el, ctx) -> { update(ctx) } }`, `{ type: 'separator' }`, and
`{ type: 'menu', label, icon, size, items(ctx) -> MenuItem[] }` (split/drop-down button). A string item is shorthand for
a small command button. Commands may define `labelFor(ctx)` / `iconFor(ctx)` for dynamic labels (Undo shows "Undo Move").

### Commands and shortcuts

`registry.command({ id, label, icon, shortcut, title?, global?, run(ctx, arg), enabled?(ctx), checked?(ctx) })`.
Commands are disabled while no document is open unless `global: true`. `app.exec(id, arg)` runs a command (errors are
reported with a toast); `app.isEnabled(id)` / `app.isChecked(id)`. `shortcut` may be a string or array; `registry.shortcut(combo, id)`
binds more. Combos use `Mod` (Cmd on macOS, Ctrl elsewhere), `Ctrl`, `Alt`, `Shift` and key names (`A`…`Z`, `0`…`9`, `=`, `-`,
`[`, `]`, `Delete`, `Backspace`, `Escape`, `Enter`, `PageUp`, `PageDown`, `ArrowLeft`, `F1`…). While text is being edited
(or a form field has focus) only combos containing Mod/Ctrl/Alt are dispatched, and commands may set
`allowInText: true|false` to override. Core command ids are prefixed by area (`file.*`, `edit.*`, `arrange.*`, `view.*`,
`page.*`, `insert.*`, `design.*`); see `features/core-*.js`.

### Icons

`icon(name)` (core/ui/icons.js) returns an `<svg>` for a sprite symbol; ribbon/menu `icon` fields accept a sprite name or raw
`<svg …>` markup. `registry.icon(name, innerMarkup)` adds a 24×24 stroke icon to the sprite. Built-in names are listed in
`core/ui/icons.js` (`ICON_NAMES`).

### Events (`app.on(event, fn)` returns an unsubscribe function)

| event | payload | when |
| --- | --- | --- |
| `doc-change` | `{ session, label, undo?, redo?, reverted? }` | after every transaction / gesture commit / undo / redo |
| `preview` | `{ session, ids: string[]|null }` | during a gesture (`app.preview(ids)`) |
| `selection` | `Element[]` | selection changed |
| `page` | `pageIndex` | current page changed (also on entering/leaving master mode) |
| `view` | `session.view` | zoom/scroll/master-mode changed |
| `session` | `DocSession|null` | current document tab changed |
| `sessions` | `DocSession[]` | a document was opened or closed |
| `session-closed` | `DocSession` | a document tab closed |
| `dirty` | `DocSession` | a document's saved/unsaved state flipped |
| `render` | `{ session, pageIndex, container }` | the canvas finished rendering a page |
| `edit-start` / `edit-end` | `{ frameId, root, session }` | in-place text editing began / ended |
| `saved` | `{ session, path, name }` | a document was saved |

### App additions

- `app.ctx()` builds the context; ctx also has `master` (the master being edited, or null).
- `app.page` is the editing surface (the current page, or the master in master mode); `app.isMasterMode`, `app.master`,
  `app.setMasterMode(on, masterIndex?)`, `app.setView(patch)`.
- `app.transact(label, fn, { coalesce })` — steps with the same `coalesce` key merge (keys starting `session:` always
  merge; others within 1.5 s). Calling `app.select()` inside `fn` is captured as the step's selection. A transaction during
  an active gesture is folded into the gesture.
- `app.addFlusher(fn)` / `app.flush()` — commit pending UI state (text editing, focused inputs) before save, close,
  undo/redo, document switches.
- `app.setEditing({ frameId, root } | null)`, `app.editing` — see Text editing.
- `app.selectionIds`, `app.dirtySessions()`, `app.addSession(doc, opts)`, `app.newDocument(opts)`, `app.activate(session)`,
  `app.removeSession(session)` (no prompt; use `app.files.close(session)` for the Save/Don't Save flow).
- `app.prefs` (core/prefs.js): per-user view preferences (`get('guides.grid')`, `set`, `toggle`, `on('change')`).
- `app.canvas`: `zoomTo(z, anchor?)`, `zoomIn()`, `zoomOut()`, `fitPage()`, `fitWidth()`, `actualSize()`,
  `clientToPage(x, y) -> { x, y, pageIndex }`, `nodeFor(id)`, `scrollToElement(id)`, `setTool(tool)` (`'select'`, `'hand'`,
  `{ kind: 'text'|'shape'|'line'|'picture', shape? }`), `requestRender()`.
- `app.files`: `newDocument(opts)`, `open()`, `openText(text, { path, name, handle })`, `save(session?)`, `saveAs(session?)`,
  `close(session?)`, `closeAll()` (Save / Don't Save / Cancel per dirty document; resolves true when everything closed).
- `app.ui.dialog({ title, body (html string or Node), fields?, buttons?, width?, onRender?(root) })` resolves
  `{ button, values }` (or `null` when dismissed); `fields: [{ name, label, type: 'text'|'number'|'length'|'select'|'checkbox'|'color'|'textarea'|'radio', value, options?, min?, max?, step?, unit? }]`
  (`length` fields accept typed units such as `2.5in` and return px). `app.ui.confirm(title, html, okLabel)` → boolean;
  `app.ui.prompt(title, label, value, opts)` → string|null; `app.ui.toast(msg, { label, run }?)`;
  `app.ui.colorPicker(anchor, value, onPick, opts?)` (theme + standard + recent + custom + no colour; `onPick(value)` gets
  `'@accent'`-style theme refs, `#rrggbb` or `'transparent'`); `app.ui.contextMenu(x, y, items)` with
  `MenuItem = { label, icon?, shortcut?, command?, arg?, run?(), disabled?, checked?, danger?, submenu? } | '-'`.

### Rendering

`renderPage(container, doc, page, { mode, pageIndex, record, showHidden, selectableMasters })` (core/render/index.js).
Element renderers get `rctx = { doc, page, pageIndex, mode, record, layout, resolveField(name, frame), isMaster }`
where `layout` is the `layoutStories()` result for the page. `record` is a merge record object `{ column: value }` (or a
function `name -> value`). Field resolution: `#page` → page number (masters on a page render that page's number; master
mode renders `#`), `#pages` → page count, `#date` → locale date, other names → `record[name]` (falls back to the «NAME»
placeholder). Each element node has `data-id`, class `el el-<type>`; hidden elements are skipped unless `showHidden`.

### Text editing

Double-click / Enter on a text frame calls `app.textEdit.start(frameId, { caret })`; the frame's content element becomes
`contenteditable` and `app.editing = { frameId, root, session }` (`root` is the contenteditable element). The story HTML is
shown unflowed in the head frame while editing (linked frames show their flowed fragments). Input is committed through
`sanitizeHtml` into `doc.stories[storyId].html` on idle (~600 ms), on blur and on `app.textEdit.commit()`; one editing
session is one undo step ("Edit Text"). `app.textEdit.stop()` ends editing (Esc, click outside). Formatting features can run
`document.execCommand` / range operations on `root` and then call `app.textEdit.commit()`.

### Desktop IPC channels

Renderer → main (`folioDesktop.invoke`): `file:open` → `{ path, name, text } | null`; `file:open-path` (path) → same
(.folio/.json regular files only; renderer-supplied paths are not trusted for silent saves); `file:save`
`({ path, text, suggestedName, saveAs })` → `{ path, name } | null`; `recovery:list` → `[{ id, title, filePath, savedAt, size }]`;
`recovery:save` `(id, text, meta)`; `recovery:read` (id) → text|null; `recovery:remove` (id); `store:get` (key) → value;
`store:set` (key, value); `store:recent` → recent files `[{ path, name, openedAt }]`; `store:recent-add` (path);
`store:recent-remove` (path); `app:info` → `{ version, platform }`.
`folioDesktop.send`: `app:ready`, `app:theme` ('system'|'light'|'dark'), `app:doc-state` `({ dirty, names })`,
`app:close-ack`, `app:close-now`, `app:close-cancel`.
Main → renderer (`folioDesktop.on`): `file:opened` `{ path, name, text }`, `app:close-request`, `menu:command` (command id, arg).
Export channels are owned by `desktop/ipc-export.js`; core/platform.js calls `export:save-binary`
`({ data, suggestedName, filters })`, `export:save-folder` `({ files: [{ name, data }] })`, `export:pdf`
`({ widthIn, heightIn, suggestedName })` and `print:print` `({ copies, duplex, landscape, silent })`.
