Install

Windows

  1. Run the downloaded Folio-Publisher-Setup file.
  2. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway (the installer is not code-signed).
  3. Pick a folder and finish. Folio appears in the Start menu and opens .folio files.

macOS

  1. Open the disk image and drag Folio Publisher to Applications.
  2. The first time you open it, macOS may say it cannot verify the developer: open System Settings → Privacy & Security and click Open Anyway (or Control-click the app and choose Open on macOS 14 and earlier).
  3. You only need to do this once.
