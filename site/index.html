Install in a minute

  1. Run the downloaded Folio-Publisher-Setup file.
  2. Allow it. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway — the installer isn’t code-signed.
  3. Done. Folio is in the Start menu and opens .folio files.
